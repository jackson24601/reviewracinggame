# Review Race

A web-based classroom horse race for review activities. Old-school VGA graphics, no install, no login.

Open `index.html` in a browser (Chrome, Edge, Firefox, or Safari). For a projector, use **FULL SCREEN**.

## How to run a race

1. Choose the number of teams, from **2** to **10**.
2. The track appears and a **3-2-1-GO** countdown starts right away.
3. Every team has a different color horse and jockey.
4. Horses crawl at first. When a team earns a review point, press that color's **+** button (or keys **1-9** and **0** for team 10).
5. Each awarded point makes that horse a little faster. Right-click a plus button if you tapped the wrong team.
6. Each time a horse finishes a lap, that team scores **+1 lap**. They keep racing and can score again on the next lap.

Use **NEW RACE** to pick a different number of teams.

## Tips for class

- Put the window on the projector and award points from the keyboard while you walk the room.
- The infield board and the buttons both show lap totals.
- **AWARDED** on each button is how many review points you have given that team.
- Sound is square-wave beeps. Mute from the bar if the room is already loud.
